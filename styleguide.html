Shadow SSO Design Guidelines

Visual language of the hosted auth pages (api/webauth/templates) and the admin add-in, adopted from the Pirat UI: zinc surfaces over a deep crimson/navy gradient, blue accent, compact and calm. Every example below uses the real production stylesheet.

Principles

Keep it quiet: one accent colour, translucent surfaces, small radii, short motion.

  • Tokens only. Use var(--…) or token utilities (bg-primary, text-muted) — no raw hex in templates.
  • Border radius never exceeds 4px. Everything — cards, avatars, switches, badges — is 0–4px. No pills, no circles.
  • One accent. --primary is tenant-brandable; text on it is always --on-primary.
  • Single column. Auth pages are one centred card; injected UI stacks below it.
  • Text-length safe. Pages are translated (en/hu/de/fr); never size UI to English strings.

Build & Tailwind

Styles are written with Tailwind CSS v4 and imported by templates — no inline <style> blocks (the only exception is the tenant --primary override).

Radius & spacing

Maximum radius is 4px. Tailwind's rounded-* scale is clamped in @theme, so even rounded-full and rounded-3xl resolve to ≤ 4px. Form groups are 18px apart; card padding is 36×32 (28×22 on mobile).

Do & Don't

✓ Use token utilities (bg-primary, text-muted) and component classes.

✗ Hardcode #6366f1, or white text on the blue accent.

✓ Keep radii at 4px or less — always.

✗ Pills, circles, border-radius: 50% or 99px.

✓ Keep layouts fluid so German/Hungarian strings wrap.

✗ Fixed-width buttons or labels sized to English.

✓ Import /dist/app.css; add new styles under src/ and rebuild.

✗ Inline <style> blocks or style="" attributes in templates.
